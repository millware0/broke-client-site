# Broke Client website

Independent informational site for Broke Client (Minecraft Java Edition 1.21.1 / Fabric).

## Publish on GitHub Pages

Upload `index.html`, `style.css`, and `script.js` to the repository root. Go to Settings → Pages → Deploy from a branch → main / root.

To connect a custom domain, follow the official GitHub Pages DNS instructions. Add the domain in Settings → Pages only after DNS configuration.

The site is independent and is not affiliated with Microsoft or Mojang Studios. Microsoft login is described as in development; update the text only when the feature is working.
