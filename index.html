Broke Client — независимый сторонний проект для Minecraft: Java Edition. Цель проекта — удобное управление аккаунтами и аккуратный интерфейс.

Вход через Microsoft разрабатывается с использованием официальной авторизации. Для доступа к Minecraft Services приложению может потребоваться отдельное одобрение.
